# CLAUDE.md — правила для Claude у цьому проєкті

## Мета проєкту

Тестове завдання «Детекція птахів на відео з YOLO26n».

Потрібно дотренувати (fine-tune) модель YOLO26n (`yolo26n.pt`) для пошуку птахів (клас `bird`),
зберегти найкращі ваги, порахувати метрики якості та показати роботу моделі на відео
(вхідне відео → відео з рамками навколо птахів).

Строк — 2 дні, тому: просте рішення краще за «правильне, але складне».
Деталей завдання (джерело датасету, вимоги до метрик) НЕ вигадуй — якщо їх немає в цьому файлі, запитай мене.

## Про мене і середовище

- Я JS-розробник, на Python пишу вперше. Англійської не розумію.
- Windows 11, PowerShell, VSCode.
- GPU: GeForce GTX 1650 Ti, 4 ГБ (ноутбук). Python 3.14, PyTorch з CUDA (збірка cu126).
- Віртуальне середовище `.venv` уже створене, бібліотеки встановлені.
- Команди для терміналу давай для PowerShell. Скрипти запускай через `.\.venv\Scripts\python.exe`
  (так не залежимо від політики виконання скриптів PowerShell).
- Нові для Python речі пояснюй коротко, за потреби порівнюй з JS.
  Повідомлення про помилки, які бувають англійською, перекладай.

## Спілкування

- Спілкуйся зі мною українською.
- Після змін коротко пояснюй українською, що зроблено і чому.
- Тексти логів та `help` в argparse — теж українською (я їх читаю).
- `README.md` — українською, якщо я не скажу інакше.

## Правила коду

- Коментарі і docstring — українською. Назви змінних, функцій, класів — англійською.
- Код має бути сумісним з Python 3.10+ (у мене 3.14, але не користуйся новішим синтаксисом і бібліотеками):
  - без `type X = ...` та `def f[T](...)` (3.12);
  - без однакових лапок усередині f-рядка, напр. `f"{d["k"]}"` (3.12);
  - без `except*`, `tomllib`, `typing.Self`, `StrEnum`, `datetime.UTC` (3.11);
  - без `Path.walk()`, `itertools.batched` (3.12);
  - без t-рядків (3.14).
- Type hints для параметрів і значень, що повертаються. `X | None` — можна (3.10).
- `pathlib.Path` замість `os.path`.
- `logging` замість `print` (налаштування — одна функція `setup_logging()`).
- Кожен скрипт: `argparse` з розумними дефолтами, функція `main()` і `if __name__ == "__main__":`.
  (На Windows це ще й обов'язково для DataLoader із кількома процесами.)
- Функції короткі: одна функція — одна задача.
- Без зайвої складності: ніяких класів, конфіг-систем і абстракцій, якщо вистачає простих функцій.

## Залежності

Дозволені лише: `ultralytics`, `torch`, `torchvision`, `opencv-python`, `numpy`, `requests`, `tqdm`
(і стандартна бібліотека Python). Потрібен інший пакет — спершу запитай мене.
Версії — у `requirements.txt` (прямі залежності, без повного `pip freeze`).

## Навчання і ресурси

- НЕ запускай довге навчання сам — давай мені готову команду для PowerShell.
  Швидкі перевірки (`--help`, 1 епоха на маленькій вибірці, до ~2 хвилин) можна.
- 4 ГБ відеопам'яті: стартові значення `imgsz=640`, `batch=8`, `workers=2`.
  Усе це винось в аргументи argparse. Якщо CUDA не вистачає пам'яті — спершу зменшуй `batch`, потім `imgsz`.

## Цільова структура проєкту

```text
bird-detector/
├── CLAUDE.md             # ці правила
├── README.md             # як встановити, підготувати датасет, навчити, запустити на відео; метрики
├── requirements.txt      # прямі залежності з точними версіями
├── .gitignore
├── prepare_dataset.py    # готує датасет у datasets/ (формат YOLO)
├── train.py              # навчання; best.pt і metrics.json кладе в weights/
├── predict_video.py      # детекція птахів на відео: вхідне відео → відео з рамками
├── data/
│   └── bird.yaml         # конфіг датасету для Ultralytics
├── weights/
│   ├── best.pt           # найкращі ваги після навчання (комітимо)
│   └── metrics.json      # метрики якості (mAP, precision, recall тощо)
└── examples/
    ├── input.mp4         # приклад вхідного відео
    └── output.mp4        # результат роботи predict_video.py
```

Поза git (див. `.gitignore`): `.venv/`, `datasets/`, `runs/` та `*.pt` у корені
(наприклад, стартові ваги `yolo26n.pt`). Файл `weights/best.pt` — комітимо.
`bus.jpg` у корені — тестова картинка для перевірки, у структуру не входить.
